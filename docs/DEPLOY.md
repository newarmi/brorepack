# Как запустить BROREPACK целиком — инструкция для накуренных 🌿

Читай сверху вниз и делай по одному шагу. Ничего не пропускай, даже если кажется, что «и так понятно».
Всё займёт примерно час. Если что-то сломалось — внизу есть раздел «Всё сломалось».

---

## Что вообще получится

```
Клиент в Telegram ──▶ бот ──▶ кнопка «Собрать плашку»
                                   │
                                   ▼
                 Mini App (сайт на GitHub Pages, бесплатно)
                                   │
                                   ▼
                 Бэкенд на Google Apps Script (бесплатно)
                     │            │              │
                     ▼            ▼              ▼
             Google Таблица    FACEIT API     Оплата ЮKassa
              (все заказы)   (уровень и ELO)  (через Telegram)
```

Своего сервера нет и платить за хостинг не нужно.

## Какие аккаунты понадобятся

- **Telegram** — твой обычный.
- **Google** — лучше отдельный для магазина: там будут лежать бэкенд и таблица с заказами.
- **GitHub** — бесплатный, на нём будет висеть само приложение. Регистрация: https://github.com/signup
- **FACEIT** — твой обычный, нужен только чтобы получить ключ.
- **ЮKassa** — понадобится, когда будешь брать настоящие деньги. Для тестов не нужна.

Заведи заметку «BROREPACK ключи» и складывай туда всё, что будешь копировать по ходу.
**Никому эти ключи не показывай.**

## Этап 0. Готовим компьютер (один раз)

Открой программу **Терминал** (Cmd + Пробел → набери «Терминал» → Enter).
Команды копируй по одной, вставляй в терминал и жми Enter.

**0.1. Git.** Проверь, что он есть:
```bash
git --version
```
Если выскочило окно «установить инструменты разработчика» — соглашайся и жди окончания.

**0.2. Node.js 22.** Ставим через nvm:
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```
Закрой терминал, открой заново, потом:
```bash
nvm install 22
```

**0.3. pnpm** (менеджер пакетов проекта):
```bash
corepack enable
```

**0.4. GitHub CLI** (чтобы не мучиться с паролями GitHub). Нужен Homebrew — если его нет, поставь с https://brew.sh. Потом:
```bash
brew install gh
```
```bash
gh auth login
```
Отвечай: **GitHub.com** → **HTTPS** → **Yes** → **Login with a web browser**. Откроется браузер — подтверди.

**0.5. Заходим в проект и ставим зависимости:**
```bash
cd ~/Desktop/development/AlexArrow
```
```bash
nvm use
```
```bash
pnpm install
```

Дальше все команды запускай из этой папки. Если закрыл терминал — снова сделай `cd …` и `nvm use`.

## Этап 1. Собираем ключи

**1.1. 🤖 Бот.** В Telegram открой **@BotFather** → `/newbot` → придумай название → придумай
юзернейм, который кончается на `bot` (например `brorepack_bot`). BotFather пришлёт токен вида
`123456:AAH...` → в заметку.

**1.2. 🆔 Твой Telegram ID** — по нему приложение поймёт, что админ — ты.
Открой **@userinfobot** → Start → число `Id: 123456789` → в заметку.

**1.3. 🎮 Ключ FACEIT** — без него не будет настоящих уровня и ELO.
1. Зайди на https://developers.faceit.com под своим FACEIT.
2. **App Studio** → создай приложение (название любое).
3. Открой приложение → **API Keys** → создай ключ, тип **Server side** → скопируй сразу → в заметку.

**1.4. 💳 Тестовая оплата.** В **@BotFather**: `/mybots` → твой бот → **Payments** → **ЮKassa** →
тестовое подключение (Test). Пройди шаги, которые попросят. Получишь токен, в нём будет `TEST` → в заметку.

**1.5. (По желанию) Оформи бота.** В @BotFather: `/mybots` → бот → **Edit Bot** → описание и аватарка.

## Этап 2. Бэкенд в Google

**2.1.** Открой https://script.google.com/home/usersettings (под Google-аккаунтом магазина)
и включи **Google Apps Script API**.

**2.2.** Войди в Google из терминала. Откроется браузер — выбери аккаунт магазина, разреши всё:
```bash
pnpm --filter @brorepack/gas exec clasp login
```

**2.3.** Создай проект и залей код:
```bash
pnpm --filter @brorepack/gas run build
```
```bash
pnpm --filter @brorepack/gas exec clasp create --type standalone --title "BROREPACK API" --rootDir dist
```
```bash
pnpm --filter @brorepack/gas run push
```

**2.4.** Открой редактор:
```bash
pnpm --filter @brorepack/gas exec clasp open-script
```

**2.5. Создаём таблицу заказов.** В редакторе вверху выбери функцию **setup** → **«Выполнить»**.
Google напугает табличкой про разрешения. Жми: «Проверить разрешения» → свой аккаунт →
«Дополнительные настройки» → «Перейти на страницу BROREPACK API (небезопасно)» → «Разрешить».
Это твой собственный скрипт, такое предупреждение у всех.
На Google Диске появится таблица **«BROREPACK — заказы»**. ✅

**2.6. Вписываем ключи.** Слева шестерёнка «Настройки проекта» → внизу «Свойства скрипта» →
«Изменить свойства скрипта» → добавь по одному:

| Свойство | Что вписать |
|---|---|
| `BOT_TOKEN` | токен бота (1.1) |
| `ADMIN_IDS` | твой Telegram ID (1.2). Несколько админов — через запятую |
| `FACEIT_API_KEY` | ключ FACEIT (1.3) |
| `PAYMENT_PROVIDER_TOKEN` | тестовый токен ЮKassa (1.4) |
| `DEV_AUTH_BYPASS` | `0` |

«Сохранить свойства скрипта».

**2.7. Публикуем бэкенд.** Синяя кнопка **«Начать развертывание»** → «Новое развертывание» →
шестерёнка рядом с «Выберите тип» → **«Веб-приложение»**:
- «Выполнять как»: **Я**
- «У кого есть доступ»: **Все** ← самое важное, не перепутай!

«Развернуть» → скопируй **URL веб-приложения** (кончается на `/exec`) → в заметку как «адрес бэкенда».

**2.8. Проверка.** Открой адрес бэкенда в браузере. Должно быть `{"ok":true,"data":{"ok":true}}`. 🎉

**2.9.** В «Свойствах скрипта» добавь `WEBHOOK_URL` = адрес бэкенда.

**2.10.** Выбери функцию **setWebhook** → «Выполнить». Теперь бот получает сообщения через Google.

## Этап 3. Приложение на GitHub Pages

**3.1. Сохраняем код в git:**
```bash
git add -A
```
```bash
git commit -m "BROREPACK"
```
```bash
git branch -M main
```

**3.2. Создаём репозиторий на GitHub** (публичный — бесплатный GitHub Pages работает только с такими;
секретов в коде нет, все ключи лежат в Google):
```bash
gh repo create brorepack --public --source=. --remote=origin
```

**3.3. Включаем Pages.** Открой репозиторий в браузере:
```bash
gh repo view --web
```
**Settings** → слева **Pages** → в «Source» выбери **GitHub Actions**.

**3.4. Даём приложению адрес бэкенда.** Там же **Settings** → **Secrets and variables** →
**Actions** → вкладка **Variables** → **New repository variable**. Добавь две переменные:
- `GAS_URL` = адрес бэкенда (`…/exec`)
- `BOT_URL` = `https://t.me/<юзернейм_бота>`

**3.5. Заливаем код — приложение соберётся само:**
```bash
git push -u origin main
```
В репозитории открой вкладку **Actions** → там крутится «Deploy Mini App». Дождись зелёной галочки ✅
(пара минут). Адрес приложения: `https://<твой-логин-github>.github.io/brorepack/` → в заметку.

## Этап 4. Соединяем бота с приложением

**4.1.** В Google: «Свойства скрипта» → добавь `WEBAPP_URL` = адрес приложения (из 3.5).

**4.2.** Запусти функцию **setMenuButton** — в чате с ботом появится кнопка, открывающая приложение.

**4.3.** Запусти функцию **checkConfig** и посмотри журнал внизу. Там написано, всё ли настроено.
Если есть жалобы — поправь то, что он просит.

---

## Этап 5. Проверяем всё целиком 🎯

1. Открой бота → `/start` → придёт приветствие с кнопкой «Собрать плашку».
2. Открой приложение → выбери дизайн → введи свой ник FACEIT → **сверь уровень и ELO с приложением FACEIT**,
   они должны совпасть.
3. Дальше → заполни доставку → «Оплатить». Платёж тестовый, деньги не спишутся. Тестовые карты —
   в документации ЮKassa, раздел «Тестовые банковские карты».
4. После оплаты бот напишет «Заказ №… оплачен», а тебе (как админу) придёт сводка заказа.
5. Открой в приложении **«Админка»** → заказ на месте. Поставь «В печати» → клиенту придёт сообщение.
6. Нажми «Прислать файл для печати в чат» → бот пришлёт SVG и PNG для типографии.
7. Открой Google Таблицу — заказ там тоже есть.

Если всё сработало — магазин работает. 🍾

## Этап 6. Включаем настоящие деньги 💰

1. Заключи договор с ЮKassa (нужен ИП или самозанятость).
2. В @BotFather: `/mybots` → бот → **Payments** → ЮKassa → **боевое** подключение → новый токен.
3. В «Свойствах скрипта» замени `PAYMENT_PROVIDER_TOKEN` на боевой.
4. ⚠️ Перед настоящими продажами нужны **фискальные чеки (54-ФЗ)** — это отдельная доработка кода,
   попроси разработчика.

## Как жить дальше

**Посмотреть заказы** — «Админка» в приложении (по умолчанию показывает текущие: оплачен, в печати,
отправлен). Таблица — для истории и выгрузок.
⚠️ Статус меняй **только в админке**: если поменять его прямо в таблице, клиент не получит уведомление.

**Добавить ещё одного админа** — допиши его Telegram ID в `ADMIN_IDS` через запятую. Сразу работает.

**Поменять цены или шаблоны** — файл `packages/shared/src/catalog.ts`. После правки обнови **и приложение,
и бэкенд** (цены считает сервер — если обновишь только одно, суммы разъедутся):
```bash
git add -A
```
```bash
git commit -m "Новые цены"
```
```bash
git push
```
…и обнови бэкенд, как ниже.

**Обновить бэкенд** — одного `push` мало, нужна новая версия:
```bash
pnpm --filter @brorepack/gas run push
```
Потом в редакторе Google: «Развертывание» → «Управление развертываниями» → карандаш ✏️ →
«Версия»: **Новая версия** → «Развернуть». Адрес `/exec` не меняется — больше ничего трогать не надо.

**Обновить приложение** — просто `git push` (как выше), GitHub пересоберёт всё сам.

## Всё сломалось 🔥

| Что видишь | Что делать |
|---|---|
| Адрес бэкенда открывает вход в Google вместо `{"ok":true}` | в развёртывании доступ не «Все». Создай новое развертывание с доступом **Все** и обнови `WEBHOOK_URL`, `GAS_URL` |
| Бот молчит на `/start` | запусти **checkConfig** — он покажет последнюю ошибку бота. Потом снова **setWebhook** |
| В приложении «Тестовые данные, не из FACEIT» | нет `FACEIT_API_KEY` в свойствах или там стоит `FACEIT_MODE=mock` — удали это свойство |
| «Не нашли такого игрока» | ник нужен с FACEIT (не из Steam), регистр важен |
| Кнопка в боте не открывает приложение | `WEBAPP_URL` должен начинаться с `https://` и вести на GitHub Pages. Потом снова **setMenuButton** |
| На GitHub в Actions красный крестик | открой его и прочитай ошибку; чаще всего не задана переменная `GAS_URL` (шаг 3.4) |
| Поменял код, а ничего не изменилось | бэкенд — забыл «Новую версию»; приложение — забыл `git push` |
| Оплата не проходит | проверь `PAYMENT_PROVIDER_TOKEN` и что `PAYMENTS_MODE` не стоит в `mock` |
| Админки не видно | твой Telegram ID не в `ADMIN_IDS` (или там опечатка) |
