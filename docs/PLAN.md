# BROREPACK — Telegram Mini App: план реализации

Макет: https://www.figma.com/design/h1eE9FVhdUFxGoGw0k5NfQ (5 экранов клиентского флоу).

## Что делает продукт

Клиент в Telegram вводит ник FACEIT → приложение подтягивает уровень и ELO → клиент собирает
акриловую плашку (шаблон, размер, подпись, подсветка) → оплачивает через Telegram Payments
(ЮKassa) → следит за статусом. Владелец получает заказ в боте, меняет статусы и забирает
готовый файл для печати.

## Архитектура

pnpm-монорепо, Node 22, TypeScript везде.

| Пакет | Что внутри |
|---|---|
| `packages/shared` | Типы, каталог и цены, уровни FACEIT, zod-схемы, **рендер плашки в SVG** — один код и для превью, и для печати |
| `apps/server` | Fastify 5 + grammY (бот, платежи), Prisma 6 + SQLite, клиент FACEIT Data API, проверка Telegram initData, генерация файлов для печати (SVG с вшитыми шрифтами + PNG 300 dpi через resvg) |
| `apps/web` | Vue 3 + Vite + TS + Pinia + Vue Router, Telegram WebApp API (MainButton, BackButton, openInvoice, requestContact), экраны из Figma + админка |

В проде сервер раздаёт собранный фронт со своего домена — один процесс, один деплой.

## Ключевые решения

- **Плашка = SVG-шаблон с подстановкой полей** (`renderPlaqueSvg`). Превью в приложении и файл
  для типографии рендерятся одной функцией, поэтому совпадают один в один.
- **Цены и уровень считает сервер.** Клиент присылает только ник и выбор; сервер сам заново
  запрашивает FACEIT и пересчитывает сумму — подделать ELO или цену нельзя.
- **Режимы для разработки:** `FACEIT_MODE=mock` (без API-ключа), `PAYMENTS_MODE=mock`
  (без токена ЮKassa), `DEV_AUTH_BYPASS=1` (запуск в обычном браузере без Telegram).
- **Файл для печати админ получает прямо в чат с ботом** — кнопка в админке.

## Этапы

1. Каркас монорепо, `shared`-контракт, рендер плашки, API-контракт (`docs/api.md`).
2. Бэкенд и фронтенд параллельно по контракту.
3. Интеграция: локальный запуск в моках, прогон всего флоу в браузере, фиксы.
4. Запуск (нужны аккаунты владельца): бот в @BotFather, токен ЮKassa, ключ FACEIT,
   VPS/хостинг с HTTPS, домен. Чек-лист — в `README.md`.

## Не входит в MVP (следующие итерации)

- Интеграция API СДЭК (расчёт доставки, виджет ПВЗ) — пока фиксированная цена и адрес текстом.
- Фискальные чеки 54-ФЗ через ЮKassa (`provider_data.receipt`) — нужно перед боевыми продажами.
- Уведомление «ты апнул уровень — закажи новую плашку» (FACEIT webhooks), промокоды, рефералка.
- Вылеты под печать (bleed) и PDF — уточнить требования у типографии.
